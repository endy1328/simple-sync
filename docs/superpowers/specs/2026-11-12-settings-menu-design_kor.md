# simple sync 1.5.0 설정 메뉴

사용자 요청에 따라 창 제목 표시줄 아래에 기본 WinForms MenuStrip을 배치한다.

- 설정 → 구글 계정: 기존 계정 관리 창을 연다. 동기화 중에는 비활성화하고, 창을 여는 동안 자동 실행 타이머를 정지하는 기존 동작을 유지한다.
- 설정 → 스킨: 기존 내장 스킨을 하위 메뉴로 제공하고 현재 선택을 체크한다.
- 설정 → 언어: 한국어·English 선택을 제공하고 현재 선택을 체크한다.
- 스킨·언어 변경은 기존 설정 저장 및 즉시 반영 동작을 사용한다. 메뉴에도 테마와 현지화 문구를 적용한다.
- 동기화 쌍에 적용하는 연결 설정과 필터, 실행·중지·쌍 관리 버튼은 툴바에 유지한다.
- 기존 설정 스키마는 변경하지 않는다. 설치 파일은 별도 요청 시 생성한다.

검증: STA UI 테스트에서 메뉴 구조, 동기화 중 계정 메뉴 비활성화와 복원, 언어 전환, 현재 언어·스킨 체크 표시를 확인한다. 기존 전체 콘솔 테스트와 Release 빌드를 수행한다.
